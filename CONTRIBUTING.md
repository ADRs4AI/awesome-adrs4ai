# Contributing a row

One pull request, one row, this shape:

```markdown
- 📖 [project-name](https://github.com/you/project) — what it is, in one honest line. 🙋 🤝
```

**The rules, all of them:**

1. **The link must be public and alive** — rows are verified by visiting, not by trusting.
2. **Your deliberation status is your own declaration**: 📖 the record ships with the code · 📘 a record exists and is declared, but is kept · 📑 model-written digests ship, the record is kept. Pick the one that is true; the legend in the README says what each means. **The list renders, never re-rules.** (Rows for this organization's own projects cite its licensing census rather than re-declaring.)
3. **Welcome glyphs are promises**: 🙋 you triage issues · 🤝 you review PRs · 🪴 you are looking for maintainers. Carry only the ones you mean.
4. One line per project. The row is a listing, not a pitch — the honest line outsells the superlative one.
5. Practicing the methodology means your project keeps a deliberation record (ADRs, seeds, or equivalent) as part of how it is built — in whatever tool. It does not require this organization's tooling.

Questions before PRing? [Discussions at the front desk](https://github.com/ADRs4AI/community/discussions).

*Housekeeping*: This repository's license is deliberately, briefly absent while the organization's licensing stack settles (its ADR-0033) — the same way the community repo was born. Spec conformance (awesome-lint, code of conduct) is tracked by the maintainers.
